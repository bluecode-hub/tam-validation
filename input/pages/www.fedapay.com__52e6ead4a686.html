Une API simple pour les développeurs

Quel que soit votre language de programmation, notre solution est très simple à intégrer. En quelques lignes de codes, FedaPay est opérationel et vous êtes partis pour recevoir des paiements.
PHP 
// Renseigner la clé api de votre compte
\Fedapay\Fedapay::setApiKey(MY_API_KEY);
// Créer la transaction
$transaction = \Fedapay\Transaction::create([
    "description" => "Article 2309ART",
    "amount" => 10000,
    "currency" => ["code" => "XOF"],
    "callback_url" => "http://e-shop.com/payment/callback.php",
    "customer" => [
        "firstname" => "John",
        "lastname" => "Doe",
        "email" => "john.doe@gmail.com",
        "phone" => "+22966000000"
    ]
]);
/*
 * Générer un lien sécurisé de paiement
 * {
 *   "token": "SECURED_TOKEN",
 *   "url": "https://process.fedapay.com/SECURED_TOKEN"
 * }
 */
$token = $transaction->generateToken();
